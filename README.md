# Centro acuático: demo

Demo publicada: https://natacion-asistencia.vercel.app

- `index.html`: control de asistencia. Es la página que sirve Vercel.
- `maquetas/horarios-y-cribado.html`: pre-horario y cribado.
- `maquetas/control-asistencia.html`: copia de la maqueta de asistencia.

Son páginas estáticas: React y Babel se cargan desde CDN, así que se abren directo en el navegador y no necesitan build.
Los datos son de ejemplo.

Desplegar: `vercel --prod` desde la raíz.
